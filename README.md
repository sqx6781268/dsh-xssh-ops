# dsh-xssh-ops

[DeepSeek Harness（DSH）](https://github.com/) 的 SSH 终端插件：在 DSH 右侧面板里连接服务器、使用完整的交互式终端，同时提供命令台账、按行号读取、后台任务、文件传输和端口转发。对话中的 AI 也能通过一组工具操作同一台服务器，但**日常使用完全不需要 AI**。

## 功能

- **交互式终端**：xterm.js 终端，支持多连接分屏、跟随 DSH 深浅色主题、上滚 5000 行、终端内搜索
- **终端背景图**：本地图片作为背景（PNG/JPG/WebP/GIF 等；PNG 透明、GIF 动图按原样存储），可调遮罩强度、模糊、位置（居中/平铺/四角/边中点）与缩放百分比
- **命令编辑框**：Enter 发送 / Shift+Enter 换行（可重绑），↑/↓ 历史命令，Tab 补全（路径候选来自真实远端文件系统且**跟随终端当前目录**，命令名本地预取）
- **终端文件名识别**：终端输出里带已知后缀的文件名会加下划线，点击在「文件 / 编辑器」页签打开预览或编辑；文件页签可跟随终端当前目录（`cd` 后自动切换）。两者都有开关（跟随为父开关，识别为子开关）
- **大输出提示与会话日志清理**：终端累计输出超过阈值时提示一次（默认 256 KB，可调），避免行历史被淘汰后毫无感知；会话日志按总量（默认 500 MB）与保留天数（默认 30 天）自动清理
- **自定义提示词**：预设提示词库，可在终端选区右键菜单里直接调用，也可为每条提示词绑定快捷键
- **文件页签**：列表 / 图标（用 − / + 调图标大小）/ 详细三种视图；详细视图显示类型、大小（KB/MB 可读）、修改时间；每种文件类型有对应图标；`../` 返回上级；自定义右键菜单（新建目录 / 新建文件 / 上传 / 重命名 / 删除 / 下载 / 编辑 / 提交到会话框 / 预览）；图片在线预览（缩放、适应、下载原图，16 MB 上限）
- **编辑器页签**：与终端 / 文件 / 转发 / 日志同级；左侧是远端**文件树**（按需展开，右键新建文件/目录、重命名、删除），右侧是 Monaco 编辑器（语法高亮、行号、折叠、Ctrl+F 查找、Ctrl+H 替换、自动换行与行号开关、多文件标签、分隔条可拖动、脏标记保存）
- **其他格式预览**：基于本地打包的 [flyfish-dev/file-viewer](https://github.com/flyfish-dev/file-viewer)，离线预览 PDF、Word(doc/docx)、Excel、PPT、压缩包等；`.doc`（Word 97 二进制）由 `@file-viewer/doc` 单独解析
- **端口转发**：本地 / 远程 / 动态 SOCKS5，支持上游 SOCKS 代理与跳板链
- **日志与台账**：每条命令记录输出行区间，可按命令 ID 或内容回查输出；独立的行号只读视图；后台任务列表与降级告警
- **连接保活**：SSH keepalive、空闲时发送字符串（可配置间隔与内容）
- **登录脚本**：按服务器配置的 Expect/Send 规则表，连接后自动执行（保存时即做危险命令检查）
- **鼠标与选区**：对齐 Windows Terminal 的习惯——选中自动复制、中键粘贴、右键菜单/粘贴/无操作三选、双击词分隔符自定义
- **服务器管理**：服务器分组、共享 SSH 凭据、SOCKS 代理库、跳板链、从已保存服务器复制

## 安装

前提：已安装 DSH，并知道自己的 profile 名称（默认一般是 `default`，桌面版是 `desktop`）。

```powershell
# 从 GitHub 安装
dsh plugin --profile <你的profile> add https://github.com/sqx6781268/dsh-xssh-ops

# 或从本地仓库安装
dsh plugin --profile <你的profile> add <本仓库路径>
```

安装后**重启 DSH**。侧栏出现 `XSSH` 页签，设置页出现「XSSH 工具」即安装成功。

### 离线安装包（不联网的机器）

在仓库里执行 `npm run pack:release`，`release/` 下会产出三种包：

| 文件 | 用途 |
| --- | --- |
| `dsh-xssh-ops-<版本>.tar.gz` | 解压得到完整目录，最通用 |
| `dsh-xssh-ops-<版本>.tgz` | npm tarball，可直接作为包路径安装 |
| `dsh-xssh-ops-<版本>.zip` | 同 tar.gz，便于 Windows 资源管理器解压 |

把包拷到目标机器后任选一种：

```powershell
# A. 解压后按目录安装
tar -xzf dsh-xssh-ops-0.1.2.tar.gz
dsh plugin --profile <你的profile> add .\dsh-xssh-ops-0.1.2

# B. 直接装 npm tarball
dsh plugin --profile <你的profile> add .\dsh-xssh-ops-0.1.2.tgz
```

安装包内已包含构建好的 `lib/`（host / client / typert / remote 与 Monaco、file-viewer 的本地组件），目标机器无需再 `npm install` 或构建。

> 如果装完看不到插件，多半是包已存在但没写进 `dsh.profile.bundles`（bundles 才是实际加载表）。用 `dsh --profile <p> --dump-config` 检查输出树里有没有 `dsh-xssh-ops`；没有的话需要把包名补进 profile 的 `bundles` 数组后再重启。详见 [常见问题](#常见问题)。

## 快速上手

1. **连接**：右侧 XSSH 面板点「＋ 连接服务器」，填主机、端口、用户名与密码/私钥，点「连接并打开」。已保存的服务器可以直接在列表里选。
2. **用终端**：终端里正常输入即可；下方命令编辑框是给长命令和批量操作准备的——Enter 发送、Shift+Enter 换行。
3. **Tab 补全**：在命令编辑框里输入路径或命令前缀按 Tab。首个 Tab 补到公共前缀，多个候选时弹出键盘可选面板（↑/↓ 移动、Enter 插入、Esc 关闭）；路径候选来自远端真实文件系统，**跟随终端当前目录**（在子目录里也能补相对路径）。
4. **文件页签**：浏览远端目录、上传/下载、创建目录、重命名。
5. **转发页签**：新建本地/远程/SOCKS5 转发。
6. **日志页签**：查看命令台账（含输出行区间）、行号视图和后台任务。
7. **危险命令拦截**：高危命令会被拦下并弹出确认卡片，同时把**带逐行注释的可读版本**（作用、影响范围、风险、执行/取消方式）放进命令编辑框，方便你判断后再执行。

## 给 AI 的工具（可选）

如果你只在 DSH 里当终端用，这一节可以跳过。对话中的 AI 通过 13 个工具入口操作同一批连接与终端，每个入口用 `op` / `mode` 选择动作：

**核心 7 个**

| 工具 | 用途 |
| --- | --- |
| `xssh_connect` | 连接：`target` 选已保存服务器，或 `host`+`username`+`auth` 直连；`proxy_probe` 只探测 SOCKS5 |
| `xssh_connection` | `op: list \| disconnect` |
| `xssh_exec` | 执行一条命令并返回 stdout/stderr/cwd/退出码 |
| `xssh_read` | `mode: full \| lines`（全量捕获或按行号区间读取） |
| `xssh_write` | 向终端写入（默认带回车） |
| `xssh_command` | `op: list \| output`（命令台账与单条命令输出） |
| `xssh_exec_background` | 后台任务下发（远端临时目录优先，降级会明确告警） |

**功能包 6 个**

| 工具 | 用途 |
| --- | --- |
| `xssh_task` | `op: list \| status \| read \| delete` |
| `xssh_terminal` | `op: sessions \| context \| shell_integration` |
| `xssh_session_log` | `op: list \| search \| read` |
| `xsftp_file` | `op: list \| read \| write \| mkdir \| rename \| delete`（删除走确认卡片） |
| `xsftp_transfer` | `op: upload_dir \| download_dir` |
| `xtunnel` | `op: start \| list \| stop` |

危险命令（如 `rm -rf`）由插件拦截并弹出确认卡片，只有操作员能确认执行；被拦截的命令同样记入台账，命令编辑框里会出现带逐行注释的可读版本（作用/影响范围/风险/执行方式）。

## 项目定位

**这是一个可以独立使用的 SSH 插件，也是给 AI 协作准备的 SSH 插件。**

- **单独用**：右侧 SSH 面板里连接服务器、用完整终端、管理远端文件（文件页签 + 编辑器页签）、预览图片与 Office/PDF 文档、端口转发、会话日志。这些能力不依赖对话，也不需要 AI。
- **与 AI 协作**：同一批连接同时以 13 个工具（`xssh_*` / `xsftp_*` / `xtunnel`）暴露给对话中的 AI——它可以跑命令、读输出、传文件、开转发，所有动作都在面板里可见、危险命令会先被拦下等你确认。

> 历史说明：0.1.0 时期本插件曾 fork 自 `dsh-ssh-ops` 并统一加了 `x` 前缀（当时可与上游同装共存）。**自 0.1.1 起不再跟随上游**：不合并上游更新，功能以本仓库的 README 与真实代码为准；上游有、本插件没有的能力（数据库管理、快捷命令片段、批量工具）不会补回来，如有需要请单独评估。

## 常见问题

**装完在侧栏/设置里看不到插件**
包依赖已存在但没登记进 `dsh.profile.bundles`。用 `dsh --profile <p> --dump-config` 验证；缺失时把 `dsh-xssh-ops` 补进该 profile `package.json` 的 `dsh.profile.bundles` 数组（原子写入，别用 JSON 往返工具），再重启。

**连接成功但提示「无法自动打开终端」**
部分服务器（如 OpenWrt/dropbear）在认证完成瞬间会拒绝第一个 shell 请求，插件已内置一次自动重试；仍失败时点终端区的「打开终端」重试即可。

**Tab 补全没反应**
先确认终端处于活动状态（不是「会话已关闭」）；会话关闭时命令编辑框是禁用的。另外设置 → 快捷键 里可以确认发送规则没有把 Tab 改掉。

**背景图不显示**
在设置 → 连接设置 → 终端背景图里勾选「启用背景图」并选择图片后点保存；保存后面板会立刻刷新。

**大量输出后查不到旧命令的输出**
行日志只保留最近 2000 行 / 512 KiB，大输出会淘汰旧行；插件现在会在累计输出超过阈值时给出提示（设置 → 连接设置 → ⑤ 输出与日志）。长期方案：用 `tail -n` / `head -c` / `sed -n` 限制输出，或用后台任务把结果落文件后按行读取。

**自定义提示词配置在哪里**
设置 → 快捷键 → 「自定义提示词」折叠框（默认收起）：添加提示词、为每条提示词按组合键绑定快捷键。终端里框选内容后右键「自定义提示词」即可运行；没有配置时该子菜单显示灰色「待创建」。

**终端里文件名没有下划线，或点击打不开**
按顺序检查：① 设置 → 连接设置 → ⑤ 输出与日志 里「文件页签跟随终端路径」和「识别终端里的文件名」都要开启（后者是前者的下级开关）；② 文件名必须带已知后缀（txt/md/sh/png/jpg/mp4/mp3/pdf/docx/xlsx/zip 等）；③ 点击按**文件页签当前目录**解析——确认文件页签已经在对应目录（跟随开启时会自动同步）；如果提示「当前目录里没有 xxx」，说明两边目录不一致。

**文件页签不会跟着 cd 切换**
确认「文件页签跟随终端路径」已开启，且终端提示符是常见形式（`user@host:/path# ` 或 `~`）；自定义提示符需要告诉我实际格式再补解析规则。

**改了设置或代码不生效**
DSH 桌面版会缓存插件代码，需要完全退出再打开；本地 link 安装时还要先 `npm run build`。
