# 功能回归排查与修复记录

> 目的：记录 SOCKS 已保存代理选择及相邻功能的失效原因、修复和验收证据。
> 适用对象：维护本插件的开发者、AI 智能体与使用者。
> 当前状态：2026-10-23，基于 main `1280024`（0.1.6）完成本地修复、构建、128 项测试和 Web 浏览器验收；未提交、未发布。
> 维护方式：后续修改同一链路时更新本记录与对应回归测试；不能把组件替身测试当作外部服务器验收。

## 1. 原因与修复

| 现象 | 定位证据 | 修复 |
| --- | --- | --- |
| 新增服务器看不到已保存 SOCKS 代理选择 | 修复前在 Web 13950/Tabbit 中，新建表单默认 `proxyOpen=false`，选择器数量为 0；展开 SOCKS 后数量为 1，库中 3 项仍在。`SshResources.jsx` 将选择器放在 `proxyOpen` 内且要求库非空 | 选择器移到折叠区外，空库给出添加/保存说明，读取失败显式显示；选择后一次填入代理字段并展开详情，手填仍可折叠；下拉保留所选项 |
| 清除服务器代理密码不生效 | `SshResources.jsx` 复选框经 `setProxy("clearProxyPassword")` 写入嵌套 proxy，但提交读顶层 `form.clearProxyPassword` | 改用顶层 `set`；从认证库项切换免认证库项时清旧密码，保持密码通过 credentials 服务保存 |
| 仅配置登录后命令/导入脚本时不执行 | `startLoginScriptIfEnabled` 原先先拒绝规则禁用/空规则，尚未设置 postCommands 就返回 started:false | postCommands 独立触发现有规则 runner，空规则直接完成后由 tick 一次性发送；存在规则时仍先规则再后置命令；每服务器显式禁用不再回退全局规则 |
| 输出/日志/文件跟随/滚轮字号设置看似保存但读回旧值 | `KeepAliveSettings` 控件有值，但 save patch 未含对应 7 字段 | 提交 outputWarnKB、sessionLogAutoPruneEnabled、sessionLogMaxTotalMB、sessionLogMaxAgeDays、filesFollowTerminal、terminalFileLinks、wheelZoomEnabled，保留 0/false |
| 编辑 A 后打开 B，再回 A 时有星号却无法保存 | `SshIde` 全局 dirty 被打开 B 清为 false，而 A 文件 text/original 仍不同 | dirty 从当前文件内容差异派生；保存期间新增修改仍保持未保存状态 |
| 批量命令/登录后命令台账来源错误 | user-broadcast/login-post 未在 COMMAND_SOURCES，未知来源回落 user-editbox；登录后命令默认也未过滤 | 补两种来源，login-post 加默认隐藏列表，显式查询仍可追溯；schema 为 string，无枚举同步缺口 |
| 按命令读取多行输出出现字面反斜杠 n | `readCommandOutput` 使用 `join("\\n")`，真实 journal 输入 first/second 返回 `first\\nsecond` | 改真实换行 `join("\n")`，补精确断言 |

历史归因：SOCKS 折叠属于较早界面设计与可发现性问题，数据和传输代码仍在，并非本轮证据支持的代码删除；登录后命令原实现可追溯 `c35022d`，多文件编辑 `3a1af95`，字面换行 `4fb4a1e`。旧历史存在缺失对象 `1d46bc0`，因此不以 `git log --all` 的完整性推断全部历史。

## 3. 真实 Web 验收

沿用 `xsshv2` profile，使用本机 DSH CLI 启动 `http://127.0.0.1:13950/`，Tabbit 中用启动日志的会话 URL 完成鉴权。desktop 和 xsshv2 都已 link 到当前 repo，未重装插件、未补 peer 依赖。

已实测：

1. 新建服务器，SOCKS 手工区仍折叠时，“从代理库选择”直接可见，已有 3 项可选择；选“西藏”带入 host/port，并自动展开。
2. 在设置页添加并保存“回归验收-本地SOCKS”（127.0.0.1:13074）；新增“回归验收-本地SSH”（127.0.0.1:7171）选该库项保存；点击连接后服务器显示已连接，终端出现本地 SSH 测试 shell，编辑器能通过 SFTP 读取文件树。
3. 输出阈值 256 → 257，保存、切换设置页后读回 257，再恢复 256 并保存。
4. Monaco 编辑测试 welcome.txt，输入 REGRESSION_GUI，打开 empty.txt，再切回 welcome.txt，保存按钮可用；点保存后本地测试 SFTP 根内 welcome.txt 实际出现新内容。
5. 页面真实请求的 `/plugins/??...dsh-xssh-ops/client.js...&rev=...` 返回 200 / text/javascript，响应包含新 selectedProxyId 接线。裸 `/plugins/dsh-xssh-ops/client.js` 返回 404，不能拿它的空响应判断插件未加载。
6. 测试服务器已断开并删除，测试代理条目已删除，代理库恢复原 3 项、服务器恢复原 19 项；测试夹具后台进程已结束。清理过程一次 Tabbit 取消后先只读核实服务器已删，才清剩余代理，未重放删除。

本轮仅连接本机测试夹具，没有对业务远端主机执行命令。外部代理网络可达性不在此次验证范围内。
